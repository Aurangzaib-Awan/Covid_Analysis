# Covid_Analysis
Covid analysis of world with pakistan
## Completed Data Visualization (python) project on Codex

The main technologies used
1. Jupyter Notebook
2. Pandas
3. Matplotlib (pyplot and dates)

I imported data set of Covid-19 from github and showed the overall impact of Covid on world and compare it with Pakistan , Total people effected, Total deaths , and the countries that were most affected by it.
